# E-Commerce Website – Project Report

## Project Overview

A full-stack e-commerce website that allows users to register, log in securely, browse products, manage their shopping cart, and complete a checkout process.

## Technologies Used

* React
* Node.js
* Express.js
* SQLite
* JavaScript
* CSS
* JWT
* bcrypt

## Main Features

* User registration and secure login
* Password hashing with bcrypt
* JWT authentication
* Persistent shopping cart
* Product listing with stock information
* Checkout and payment sandbox
* Order creation and inventory updates
* Responsive user interface

## What I Learned

Through this project, I improved my understanding of full-stack development, authentication, REST APIs, database operations, shopping cart management, checkout flows, and connecting a React frontend with a backend.

## Deployment

The frontend was deployed using Vercel, and the backend was deployed using Render.
